# Changelog

## 2026-09-22 - V[1.10]
### New Features: 
* Diodes can be created with random specifications using Create.Diode("random") or "rand".
* The voltage and electric field sweeps of separate Diode instances can be visually compared on the same graph via CMP_"InsertDesiredSweep"AtEquilibrium()
* Diodes can now be named on initilisation
